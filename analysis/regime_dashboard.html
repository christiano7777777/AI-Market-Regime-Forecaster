Hidden Regimes

An autoencoder compresses 16 causal macro/vol/credit features into a 3-dimensional embedding; a Gaussian HMM fits regimes on top of that learned space. Built and validated as a standalone research model — not backtested for profit.

Alignment with known crises

Regime composition of trading days within each historical window — a sanity check the model was never trained to pass.

Trained on SPY/RSP/IWM/QQQ/VIX/HYG/LQD/TLT/GLD/UUP/USO/10Y-yield features, 2008–2026. Autoencoder + HMM both fit on data through 2021-12-31 only, then applied forward (frozen) to 2022–2026 as a genuine holdout. State count (4) chosen as the largest where every regime still averages ≥5 trading days' duration — BIC alone kept preferring more states by fitting noise as short-lived "regimes." Refit on progressively later cutoffs (2015/2018/2021) agrees with the final model on 81.6–83.7% of days for the shared 2009–2014 window.
